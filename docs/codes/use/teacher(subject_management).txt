' Notas explicativas
note right of UC4
  Título obligatorio.
  Mínimo 5 caracteres.
end note

note right of UC5
  Descripción obligatoria.
  Mínimo 50 caracteres.
end note

note right of UC6
  Definir al menos 1 objetivo.
  Máximo 10 objetivos.
end note

note right of UC7
  Estructurar entre 1 y 8 unidades.
end note

note right of UC8
  Valida que todos los campos
  obligatorios estén completos
  y cumplan las reglas de negocio.
  Si hay error, resalta y solicita corrección.
end note

note right of UC12
  Solo el docente creador puede
  modificar la asignatura.
end note

note right of UC19
  Verifica si la asignatura tiene
  recursos (videos, documentos, enlaces)
  o talleres asociados.
end note

note right of UC20
  Si tiene recursos, muestra
  la lista de elementos afectados
  para que el docente confirme.
end note

note right of UC21
  El docente debe confirmar
  la eliminación en cascada.
  Si cancela, se detiene la operación.
end note

note right of UC25
  Crea una copia exacta de la
  asignatura con el prefijo "Copia de".
  El docente puede editar el título
  después de la duplicación.
end note

note bottom of UC26
  Mantiene la estructura completa:
  unidades, recursos y talleres.
end note

@enduml
