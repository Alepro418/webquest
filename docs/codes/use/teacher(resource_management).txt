' Notas explicativas
note right of UC6
  Valida formato URL.
  Si es inválida, muestra error
  y solicita corrección.
end note

note right of UC7
  Verifica que el enlace sea
  accesible (no roto).
end note

note right of UC8
  Obtiene automáticamente
  título y descripción de la página.
end note

note right of UC15
  Tamaño máximo: 10 MB.
  Si excede, muestra error
  y sugiere comprimir.
end note

note right of UC16
  Formatos aceptados:
  PDF, DOC, DOCX, PPT.
  Si no es válido, muestra
  error y solicita otro archivo.
end note

note right of UC20
  Si el documento lo permite,
  genera una miniatura
  para previsualización.
end note

note right of UC21
  Después de agregar el recurso,
  actualiza el listado visible
  para el docente.
end note

note bottom of UC24
  Permite al docente agregar
  otro recurso sin salir del panel.
end note

note bottom of UC26
  Confirma que los recursos
  estén organizados y guardados
  correctamente.
end note
