@startuml
title Diagrama de Casos de Uso - Asignación y Actualización de Estatus Motivacional

left to right direction
actor "Sistema" as S
actor "Docente" as D

rectangle "Módulo de Estatus Motivacional" {
  usecase "Ejecutar proceso automático diario" as UC1
  usecase "Obtener estudiantes activos" as UC2
  usecase "Calcular promedio ponderado de evaluaciones" as UC3
  usecase "Determinar estatus según promedio" as UC4
  usecase "Preparar mensaje motivacional automático" as UC5
  usecase "Mostrar sugerencia al docente" as UC6
  usecase "Confirmar estatus sugerido" as UC7
  usecase "Modificar estatus manualmente" as UC8
  usecase "Personalizar mensaje motivacional" as UC9
  usecase "Registrar asignación de estatus" as UC10
  usecase "Actualizar vista del estudiante" as UC11
  usecase "Notificar al estudiante (si hay cambio)" as UC12
  usecase "Generar reporte de distribución de estatus" as UC13
  usecase "Identificar estudiantes para atención prioritaria" as UC14
}

S --> UC1
D --> UC6
D --> UC8
D --> UC9

' Inclusiones obligatorias
UC1 ..> UC2 : <<include>>
UC1 ..> UC13 : <<include>> (genera reporte automático)
UC13 ..> UC14 : <<include>> (identifica prioridades)

' Proceso por cada estudiante
UC2 ..> UC3 : <<include>> (para cada estudiante)
UC3 ..> UC4 : <<include>>
UC4 ..> UC5 : <<include>> (prepara mensaje automático)

' Intervención del docente (si está en sesión)
UC4 ..> UC6 : <<extend>> (si docente en sesión)
UC6 ..> UC7 : <<extend>> (si confirma)
UC6 ..> UC8 : <<extend>> (si modifica)
UC8 ..> UC9 : <<extend>> (opcional, personaliza mensaje)

' Registro y actualización
UC4 ..> UC10 : <<include>> (siempre)
UC10 ..> UC11 : <<include>> (actualiza vista)
UC11 ..> UC12 : <<include>> (notifica si cambio)

' Notas explicativas
note right of UC1
  Proceso programado que se ejecuta
  todos los días a las 00:00.
end note

note right of UC3
  Calcula promedio ponderado
  según última evaluación y peso asignado
end note

note right of UC4
  Umbrales de estatus:
  - >= 18 → Sobresaliente
  - 12 a 17.99 → Buen estudiante
  - < 12 → Vamos a mejorar juntos
end note

note right of UC5
  Mensajes automáticos según estatus:
  - Sobresaliente: "¡Excelente trabajo!"
  - Buen estudiante: "Vas por buen camino"
  - Vamos a mejorar: "Cuentas con mi apoyo"
end note

note right of UC6
  Si el docente está en sesión activa,
  el sistema muestra la sugerencia
  para que pueda confirmar o modificar.
end note

note right of UC8
  El docente puede seleccionar
  manualmente un estatus diferente
  al sugerido por el sistema.
end note

note right of UC9
  El docente puede personalizar
  el mensaje motivacional
  que verá el estudiante.
end note

note right of UC10
  Registra quién asignó el estatus
  (sistema o docente) y la fecha
  de asignación.
end note

note bottom of UC12
  Solo notifica al estudiante
  si ha habido un cambio
  respecto al estatus anterior.
end note

note right of UC14
  Identifica automáticamente
  a los estudiantes con estatus
  "Vamos a mejorar" para
  atención prioritaria.
end note

@enduml
