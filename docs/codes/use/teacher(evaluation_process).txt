' Notas explicativas
note right of UC6
  Rango permitido: 0 a 20.
  Si es inválido, muestra error
  y solicita nuevo ingreso.
end note

note right of UC8
  Escala automática:
  - 18-20 → 'A' (Sobresaliente)
  - 15-17 → 'B' (Distinguido)
  - 12-14 → 'C' (Aprobado)
  - 0-11 → 'D' (Por mejorar)
end note

note right of UC10
  Si observaciones < 10 caracteres,
  el sistema sugiere agregar más detalles.
end note

note right of UC11
  Sistema sugiere estatus según
  promedio histórico, pero el docente
  puede mantener o modificar.
end note

note right of UC12
  Verifica que todos los datos
  estén completos antes de guardar.
  Si falta algo, solicita completar.
end note

note right of UC13
  Actualiza el promedio general
  del estudiante tras la evaluación.
end note

note right of UC14
  Recalcula el estatus motivacional
  global del estudiante según
  últimas evaluaciones.
end note

note right of UC18
  Si la imagen no es legible,
  el docente solicita nueva entrega,
  explica el motivo, notifica al
  estudiante y marca como rechazada.
end note

note bottom of UC22
  Exporta calificaciones en formato
  PDF, Excel o CSV.
end note
