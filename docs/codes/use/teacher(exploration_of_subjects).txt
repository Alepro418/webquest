' Notas explicativas
note right of UC2
  Listado organizado por:
  - Período escolar
  - Unidad temática
  - Fecha de publicación
  Muestra: título, descripción breve,
  progreso, última actividad, recursos.
end note

note right of UC7
  Muestra título completo,
  descripción detallada,
  objetivos de aprendizaje.
end note

note right of UC8
  Recursos agrupados por tipo:
  - Video: thumbnail, duración, reproducción
  - Documento: formato, tamaño, previsualización, descarga
  - Enlace: descripción, abre en nueva pestaña
end note

note right of UC13
  Talleres asociados:
  - Pendientes (con fecha límite y botón "Realizar")
  - Completados
  - Próximos
end note

note bottom of UC16
  El estudiante puede marcar
  recursos como favoritos para
  acceso rápido.
end note

note bottom of UC17
  El sistema registra cada
  visualización para generar
  estadísticas de uso.
end note
